# Archived Java Implementation

The original Spring Boot project is in [java-stock-predictor](java-stock-predictor/).
Its source files and Maven layout are preserved for reference. To work on it:

```powershell
cd archive/java-stock-predictor
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

The active Python project's verification does not build or run this archive.
The archived configuration is historical, not the Python application's settings.
Do not reuse credentials from archived configuration; use environment variables
for the active application.
